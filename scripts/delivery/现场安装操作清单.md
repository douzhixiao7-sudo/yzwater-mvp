## 现场步骤

1. **按《软件安装流程》装齐软件**，自检通过（java 17、postgis、redis ping）。
2. **建库 + 开 PostGIS + restore dump**（见交付说明第 5 节）。
3. **改 `application-dev.yaml`** 库名/账号（启动用 `dev`）。
4. **三终端启动**：后端 jar → 管理端 `npm run dev` → 移动端 `npm run dev`。
5. **点验闭环**（交付说明第 8 节）。
6. **告知对方**：未交付名录（短信 / 真·对象存储 / GeoServer / 域名证书 / 平台免登录等）按需自建；验证码看后端日志。

## 启动命令速查

```bash
# 后端（在 yz-server/target）
java -Dloader.path=lib -jar yz-server.jar --spring.profiles.active=dev

# 管理端
cd yz-ui/yz-boot-mini-front-master && npm run dev

# 移动端
cd mobile-vue3-app && npm run dev
```

端口：后端 `48082` · 管理端 `5173` · 移动端 `3000/h5/`。
