# 软件安装流程与命令（Windows + macOS）

面向：在本机或现场电脑上，从零安装跑通本项目所需的基础软件。  
装完后，再按 **[河长制交付说明.md](./河长制交付说明.md)** 还原库、启动三端。

| 项 | 要求 |
|---|---|
| JDK | **17** |
| Maven | 3.8+（建议 3.9） |
| Node.js | **18+**（建议 20 LTS） |
| PostgreSQL | 14+（建议 15/16） |
| PostGIS | 与 PG 匹配的 3.x（**扩展**，不是另一个库） |
| Redis | 6+（建议 7） |
| Git | 任意近期版本 |

**安装总顺序：** Git → JDK 17 → Maven → Node.js → PostgreSQL + PostGIS → Redis → 自检。

---

## 1. Git

### macOS

```bash
xcode-select --install
# 或
brew install git
git --version
```

### Windows

1. 下载安装 [Git for Windows](https://git-scm.com/download/win)  
2. 新开 PowerShell / Git Bash：

```bash
git --version
```

---

## 2. JDK 17

### macOS（Homebrew）

```bash
brew install openjdk@17
echo 'export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"' >> ~/.zshrc
echo 'export JAVA_HOME="/opt/homebrew/opt/openjdk@17"' >> ~/.zshrc
source ~/.zshrc
java -version    # 必须是 17.x
```

Intel Mac 的路径可能是 `/usr/local/opt/openjdk@17`，以 `brew` 提示为准。

### Windows

1. 安装 [Eclipse Temurin 17](https://adoptium.net/) 或 Oracle JDK 17  
2. 勾选设置 `JAVA_HOME`，并加入 `Path`  
3. **新开**终端：

```bat
java -version
```

---

## 3. Maven

### macOS

```bash
brew install maven
mvn -v
```

### Windows

1. 下载 [Maven](https://maven.apache.org/download.cgi) 解压  
2. 设置环境变量 `MAVEN_HOME` = 解压目录  
3. `Path` 增加 `%MAVEN_HOME%\bin`  
4. 新开终端：

```bat
mvn -v
```

---

## 4. Node.js

### macOS

```bash
brew install node@20
# 或官网 LTS 安装包：https://nodejs.org/
node -v
npm -v
```

### Windows

1. 安装 [Node.js LTS](https://nodejs.org/)  
2. 勾选加入 PATH，新开终端：

```bat
node -v
npm -v
```

## 5. PostgreSQL + PostGIS

说明：PostgreSQL 是数据库；**PostGIS 是装在上面的空间扩展**。只装 postgres、不开 PostGIS，本项目附近设施查询会失败。

### macOS 方式 A：Postgres.app（推荐）

1. 安装 [Postgres.app](https://postgresapp.com/)，Initialize  
2. 确保带 PostGIS 扩展  
3. 命令行：

```bash
sudo mkdir -p /etc/paths.d
echo /Applications/Postgres.app/Contents/Versions/latest/bin | sudo tee /etc/paths.d/postgresapp
# 新开终端
psql --version
```

### macOS 方式 B：Homebrew

```bash
brew install postgresql@16
brew install postgis
brew services start postgresql@16
# 按 brew 提示把 bin 加入 PATH
```

### Windows

1. 安装 [PostgreSQL Windows](https://www.postgresql.org/download/windows/)，记住 `postgres` 密码  
2. 用 Stack Builder 安装 **PostGIS**，或使用带 PostGIS 的安装包  
3. 确认「SQL Shell (psql)」或命令行可用 `psql`

### 建业务库并启用 PostGIS（Win / Mac 通用）

用户名、密码以现场安装为准；示例用 `postgres`：

```bash
createdb -h localhost -U postgres yzwater_delivery

psql -h localhost -U postgres -d yzwater_delivery -c "CREATE EXTENSION IF NOT EXISTS postgis;"
psql -h localhost -U postgres -d yzwater_delivery -c "SELECT PostGIS_Version();"
```

有版本号输出即成功。

若 `psql -U postgres` 认证失败：用安装时的超级用户登录，再创建/授权 `postgres` 用户，或把后端 yaml 改成你的实际用户名。

## 6. Redis

### macOS

```bash
brew install redis
brew services start redis
redis-cli ping    # 应返回 PONG
```

### Windows

任选其一：

- [Memurai](https://www.memurai.com/)（Redis 兼容）  
- WSL：`sudo apt install redis-server && sudo service redis-server start`  
- 其他 Windows Redis 发行版  

保证本机 `127.0.0.1:6379` 可连（与 `application-dev.yaml` 默认一致）：

```bat
redis-cli ping
```

## 7. 装完自检（复制执行）

```bash
java -version
mvn -v
node -v && npm -v
psql --version
redis-cli ping
psql -h localhost -U postgres -d yzwater_delivery -c "SELECT PostGIS_Version();"
```

全部通过后，进入交付说明：**还原 dump → 改配置 → 启动三端**。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `java` 不是 17 | 检查 `JAVA_HOME` / PATH，关掉旧终端重开 |
| `psql: command not found` | 把 PostgreSQL `bin` 加入 PATH |
| `geometry does not exist` | 对业务库执行 `CREATE EXTENSION postgis;` |
| Redis 连接失败 | 确认服务已启动；检查防火墙 |
| Windows 杀毒拦截 | 把项目目录加入白名单 |
| 现场无外网 | 出发前准备离线安装包 |
