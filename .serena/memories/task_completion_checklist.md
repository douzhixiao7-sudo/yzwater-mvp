# 任务完成检查清单

## 1. 后端改动完成后
- 编译检查：`mvn -pl yz-server -am -DskipTests compile`
- 受影响模块测试：优先运行最小测试集（单测总时长控制在 60s 内）
- 若改动配置/启动逻辑：本地启动 `yz-server` 验证关键接口
- 若改动 Mapper/SQL：验证分页、条件过滤、逻辑删除、租户/权限拦截

## 2. 前端改动完成后
- 执行：`pnpm ts:check`
- 执行：`pnpm lint:eslint`（必要时再跑 `pnpm lint:style`）
- 关键页面手工回归：路由可达、接口联通、主要交互可用

## 3. 提交前通用检查
- 变更最小化：删除无用代码与临时文件，不保留过时兼容分支
- 注释与命名可读：关键流程有简明中文注释
- 不提交敏感信息：尤其 `application*.yaml` 中账号/密钥
- 记录变更影响面：涉及模块、接口、数据库对象、兼容性风险

## 4. 风险操作提醒
- 如需执行删除、强制重置、推送等高风险操作，先获得明确确认。
- 对无法在本地完整验证的项，需在交付说明里明确“未验证项 + 建议验证步骤”。
